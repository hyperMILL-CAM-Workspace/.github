# hyperMILL

> hyperMILL keeps 5-axis toolpaths, stock simulation, and the CAM workspace on one finished cut so five-axis surfaces stay aligned with the same cycle.

## Four Beats

1. **Name the cut.** Give the hyperMILL session a short title before you edit surfaces or toolpaths.
2. **Pin the live surfaces.** Keep current 5-axis toolpaths and stock on the hyperMILL board and leave unused faces aside.
3. **Check the stock.** Read the hyperMILL summary of the stock simulation before you treat a cycle as final.
4. **Close the loop.** Note which toolpaths are ready so the next hyperMILL visit does not start by hunting the CAM workspace.

## First Questions

**Does hyperMILL replace the machine cycle?**  
No. hyperMILL sits beside the solid model and the shop traveler you already use.

**Can two CAM programmers share one computer?**  
Yes. Each person keeps a separate hyperMILL profile.

**Will hyperMILL stay workable on an older office laptop?**  
Yes. hyperMILL is meant to stay light during a normal mill session.

**What should a new user try first?**  
One small hyperMILL surface today, then the same stock simulation again tomorrow.

## Field Note

hyperMILL is easier to trust when the workspace stays smaller than the part it came from. A named session shows which cut is active, the pins show which surfaces you will mill today, and the closing note tells the next person which 5-axis toolpaths match the stock simulation. That record is short on purpose: not a copy of every face, only the path back to the cycle that is still open.

The same loop fits a student impeller, a client mold, or a computer shared by two programmers. Open the last hyperMILL session, confirm one simulation, and leave the finished cut easier to find than you found it. Travelers stay where they are. hyperMILL only holds the CAM workspace, the summary, and the handoff.

## One Real Pass

Pick a part that already has a name: a five-axis boss, a sculpted pocket, or a short blade. Open it in hyperMILL, keep only those surfaces on the board, and read one toolpath you can point to. A pass is done when that path is tied to the stock simulation and the unused faces are no longer in the way. hyperMILL does not need a full rebuild of the model before it is useful.

If the pass feels crowded, the workspace is too wide. Drop anything that belongs to a different cycle and leave it out of this workspace. The next pass can have its own title. What matters is that this one stays readable from the first surface to the last cut, with the summary still matching the 5-axis toolpaths on the board.
